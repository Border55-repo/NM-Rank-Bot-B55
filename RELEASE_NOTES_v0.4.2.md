# v0.4.2

- Kontinuerlig HTML/DOM-leser for URL, sidetittel, cooldown, innlogging,
  fengsel, CAPTCHA, penger og rank.
- Cooldown-parser for `mm:ss`, `hh:mm:ss` og norsk tekst.
- Work Mode for kontinuerlig avlesning på Windows og i mobilpanelet.
- Egen Android WebView-utgave som kan lese HTML direkte på telefonen uten PC.
- Learning Mode med lokalt selector-register og treffhistorikk.
- Lokal, renset observasjonslogg og diagnostikkeksport for videreutvikling.
- Spørringsparametre, passord, cookies, sessiondata og full HTML eksporteres ikke.
- Automatisk pause ved CAPTCHA; brukeren løser den manuelt.
- Ingen anti-cheat-omgåelse, menneskeimitasjon eller automatisk klikking.
